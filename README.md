#  Operating Systems TPs – Scheduling & Memory Management

This repository contains my practical work (TP) for **Operating Systems (SE)**.

##  Content

The repository includes implementations and experiments related to:

###  CPU Scheduling (Round Robin)

* Simulation of **Round Robin algorithm**
* Process management with time quantum
* Handling arrival time, burst time
* Metrics:

  * Waiting Time
  * Turnaround Time
  * Execution order

###  Memory Management

* Implementation of memory allocation techniques:

  * Fixed Partitioning
  * Variable Partitioning
* Concepts covered:

  * Allocation & Deallocation
  * Fragmentation (Internal & External)
  * Waiting Queue
  * Rejected Processes
  * Memory merging (compaction)

##  Purpose

This work is part of my studies in **Computer Science Engineering**.
The goal is to:

* Understand core OS concepts through practice
* Improve problem-solving and algorithmic thinking
* Build clean and structured simulations
